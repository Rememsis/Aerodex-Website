AeroDex Netlify Static Version

Upload the CONTENTS of this folder to Netlify, or drag this ZIP into Netlify Deploys.

Important:
- This version is static and works on Netlify without Node/Express.
- Real Roblox OAuth cannot run on a static Netlify-only deploy because it needs a backend callback and secret.
- The included Roblox login page is a static/demo account connector using localStorage so your site does not 404.
- For real Roblox OAuth, host the backend separately on Render/Railway and connect Netlify to that API.
